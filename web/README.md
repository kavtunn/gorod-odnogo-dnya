# Город одного дня — React + TypeScript

```bash
npm install
npm run dev
```

Структура `src/`:

| Папка | Что внутри |
| --- | --- |
| `types/` | TypeScript-типы |
| `styles/` | CSS |
| `store/` | прогресс в localStorage |
| `data/` | загрузка city.json |
| `components/` | экраны и UI |

Данные и медиа — в `public/json`, `public/img`, `public/fonts`.

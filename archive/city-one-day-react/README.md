# Город одного дня

Интерактивный обучающий WEB-тренажёр: ученик проживает день в городе через ситуации по БЖД, ЗОЖ, экологии, цифровой безопасности и профессиям.

## Запуск

```bash
cd city-one-day
npm install
npm run dev
```

Открой URL из терминала (обычно http://127.0.0.1:5173).

## Что внутри

- Карта города (пробковая доска) и таймлайн дня
- 8 сцен: дом, дорога, эвакуация, столовая, река, двор, завод, чат
- Справочник, тест, личный отчёт + выгрузка памятки
- Режим учителя: фильтр по теме модуля
- Прогресс в `localStorage`

## Стек

Vite + React + TypeScript + React Router. Контент в `src/data/city.ts`.

# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: Vite + React + TypeScript + CSS modules (or plain CSS variables). SPA, client-first, content in JSON. Progress in localStorage for MVP; Firebase optional later. Chosen for school-projector demos, offline-friendly static hosting, and fast scene iteration.

## Users

- **Primary:** школьники (примерно 5–9 класс) — проживают «один день» в городе через ситуации.
- **Audience for contest jury:** оценивают мультимедийный обучающе-справочный WEB-продукт общественно значимой тематики.

## Product Purpose

«Город одного дня» — интерактивный обучающий мир: ученик проходит день (утро → школа → дорога → вечер), заходит в локации и решает ситуации по БЖД, ЗОЖ, экологии, цифровой безопасности и «профессиям города». Не лозунги — решения с последствиями. В конце — личный отчёт и памятки; есть справочник и тест.

Success: за 3–4 минуты на проекторе видно цельный мир и обучение; школа может взять продукт на урок без отдельной установки.

## Positioning

Один связный город-симулятор дня, а не набор разрозненных квизов. Механика: таймлайн дня + карта локаций + сцены (клики, диалоги, мини-тренажёры) + отчёт решений.

## Operating Context

- Урок / классный час / внеурочка, на своём устройстве школьника.
- Темы из ТЗ конкурса: ЗОЖ, патриотическое воспитание (через профессии и смысл города), охрана среды, БЖД.
- Применение: учреждения образования (и пригодно для демонстрации жюри).

## Capabilities and Constraints

**Modules**
1. Дорога и двор (БЖД)
2. Школа и эвакуация (БЖД)
3. Еда / сон / экран (ЗОЖ)
4. Река и мусор (экология)
5. Чат с незнакомцем (цифровая безопасность)
6. Профессии города (патриотика через смысл)
7. Справочник + тест + журнал результатов (localStorage)

**Flow:** карта города → локация → сцена → таймлайн дня → тест.

**Constraints**
- Только веб-приложение (браузер), без VR/натива.
- Контент сцен в JSON; анимации CSS/Lottie; короткие видео опционально.
- Без «нейросетей на всё» в MVP.
- Язык интерфейса: русский.
- Не медицинский диагноз и не замена курса первой помощи — обучение и справка.

**Undecided:** точное имя бренда (рабочее: «Город одного дня»), нужна ли сетевая синхронизация журнала класса (MVP — локально).

## Brand Commitments

- Рабочее название: **Город одного дня**.
- Тон: ясный, уважительный к подростку, без нравоучений и плакатного пафоса; последствия решений показывают сами себя.
- Визуальный мир: определяется Impeccable new-work / DESIGN.md (ещё не зафиксирован).

## Evidence on Hand

- Продуктовое ТЗ из брифа конкурса и согласованной концепции модулей (этот файл).
- Синтетический учебный контент для демо допускается и помечается как учебный материал.
- Реальных школьных логов, видеосъёмки города и лицензированных роликов пока нет — не выдумывать «кейсы школ» в маркетинговых формулировках.

## Product Principles

1. **Решение важнее слогана** — каждая сцена даёт выбор и видимое следствие.
2. **Один мир, много тем** — ЗОЖ/БЖД/экология/сеть/профессии живут в одном городе и одном дне.
3. **День целиком** — локации открываются по ходу дня, без отдельного «режима взрослого».
4. **Честность границ** — продукт учит, не ставит диагнозов и не пугает ради эффекта.

## Accessibility & Inclusion

- Управление с клавиатуры и крупный клик для проектора.
- Контрастный текст, подписи к интерактиву, не полагаться только на цвет.
- Цель: пригодно для классной демонстрации (WCAG AA как ориентир).
